# Psi Gestão Fácil – Ideia Jorge

Protótipo SaaS independente para psicólogas(os).

## V0.1
- Cadastro/login da psicóloga
- Disponibilidade configurável
- Agenda derivada da disponibilidade
- Cadastro de pacientes
- Separação entre dados do paciente e dados fiscais do tomador
- Base preparada para prontuário e financeiro novo

## Princípio do produto
Se a funcionalidade não economiza tempo, reduz erro, ajuda a receber ou melhora o atendimento, ela precisa provar por que deve existir.
